# Security policy

## What this repository is

This is a **testing checklist and research corpus**. It ships no runnable exploit aimed at a live
third-party service: every PoC is described for **researcher-owned Docker / local labs only**.

## Reporting a problem

- **A checklist item is wrong, unsafe, or has a broken reference** — open a GitHub issue.
- **A safety/ethics concern** (an item that could encourage harming third parties) — contact the
  maintainer privately via the GitHub profile [@xaferima](https://github.com/xaferima), or open a
  minimal issue without operational detail.
- **A vulnerability in a real product** that is documented or referenced here — report it to that
  vendor or CNA, **not** in this repository.

Please do **not** open public issues containing live credentials, victim data, or step-by-step abuse
of systems you do not own.
